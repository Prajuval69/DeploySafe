# GitHub, screenshots and honest resume claims

Before adding to resume, record actual OS, Python version, commands run, screenshots of dashboard using real local history, sanitized logs of successful deploy + failure + rollback, test results, release version, source tree and GitHub repo link. Suggested *conditional* bullets are in `templates/RESUME_BULLETS_CONDITIONAL.md`. Do not claim AWS/DevOps cloud deployment, Docker, Kubernetes, enterprise infrastructure experience or tests on an OS you never used. Phrase as a **local deployment automation and rollback lab**. Future enhancements can include optional GitHub Actions stdlib tests if available, but an optional remote CI workflow is not a runtime dependency and should not be represented as implemented until it is actually configured and run.
